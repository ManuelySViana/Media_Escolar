# Atividade - Calculadora de Média Escolar

### Objetivo

Desenvolver uma aplicação Flutter capaz de receber o nome e três notas de um aluno, calcular sua média e apresentar a asituação escolar.

### Conceitos trabalhados

- MaterialApp
- Scaffold
- StatefulWidget
- TextField
- TextEditingController
- ElevatedButton
- OutlineButton
- setState
- variáveis
- Conversão de texto para número
- Condicionais
- Funções
- Validação de campos

### Funcionamento

O usuário deverá informar:

- Nome do aluno;
- Primeira nota;
- Segunda nota;
- Terceira nota;

O sistema deverá calcular a média e mostrar:

- Aprovado: média maior ou igual a 7;
- Recuperação: média maior ou igual a 5;
- Reprovado: média menor que 5;
